\section{Purpose and Evidence Boundary}

This supplement records the details needed to audit the frozen study. It does
not introduce an alternative endpoint, subgroup, policy, or additional game.
All values are generated from committed aggregate artifacts, and the complete
private execution bundles remain hash-bound outside Git. The main paper's
algorithmic context follows established work on RTS bot configuration and
instance-aware tuning~\cite{mora2012noisy,fernandezAres2012map,eggensperger2019pitfalls}.

\section{Statistical Details}

The confirmatory effect first averages reciprocal starts within each
family--seed block. With 16 families and eight blocks per family, the primary
estimate is balanced across families regardless of their file count or map
revision count. The finite-cluster sandwich applies the $G/(G-1)$ correction
and a Student-$t$ critical value with 15 degrees of freedom. The two-sided
relative interval uses 2.131449545559323; the one-sided absolute lower bound
uses 1.7530503556925547.

The diagnostic family bootstrap resampled the 16 family means with replacement
100,000 times using seed 20260811. Its improvement interval is
[\ImprovementBootstrapLower{},~\ImprovementBootstrapUpper{}]. The exact
sign-flip test enumerated all $2^{16}$ sign assignments and produced
$p=\ImprovementSignFlipP{}$. Both analyses were post-confirmatory and are
sensitivity checks only, consistent with recommendations to report uncertainty
across tasks rather than treating correlated runs as independent
\cite{agarwal2021precipice}.

For the five component contrasts, ordinary intervals use the same ten-family
cluster estimator on the open development panel. Familywise intervals use a
Bonferroni two-sided critical probability of $1-0.05/(2\times5)$. The scouting
contrast is exactly zero on every paired endpoint and therefore has zero
observed variance; the paper reports that degeneracy rather than assigning it
a conventional interval.

\section{Transparent Adaptation and Failure Ledger}

\paragraph{Retired method v1.}
The first planned method compared a three-feature map-conditioned finalist
selector with a global finalist. Its scheduled development effect was
$-0.025$, and training-only leave-one-family checks showed no positive selector
gain. The method was retired. Method v2 removed conditioning and introduced a
common-seed finalist championship. It used the same training-only candidate
pool but a fresh development family pool; sealed test identities and outcomes
remained inaccessible throughout adaptation.

\paragraph{Development interface failure.}
An early source-bound development phase-2 campaign (array 21919472) counted 88
launches. A basename validator rejected four committed \texttt{.mpr} map
shards after launch, producing 72 technically clean completions and 16
technical failures. No winner or score was inspected. Because a post-launch
failure invalidated the stage, none of its 72 completions entered the analysis.
After a committed extension-validation repair, the entire three-phase protocol
restarted from phase 1 under new arrays; no successful shard was reused.

\paragraph{Zero-launch failures.}
Optimizer arrays 21655409--21655413 were cancelled after a runtime-tree change
before any counted launch. Component array 21938264 failed uniformly during
private-role loading before creating a results directory or counted launch.
Its failure record has SHA-256
\nolinkurl{9481d3055d0f79c7b3bc021dbc95647cca52363d13ad3be346125881c3954b89}.
A prospective routing repair preceded the complete component array 21938403.
Neither zero-launch failure contributed a game.

\section{Artifact Reproduction}

The anonymous artifact contains the paper inputs and author-owned code but not
third-party game assets. After acquiring the pinned dependencies and map bytes
whose hashes appear in the manifests, the paper-only checks require no game
launch:

\begin{verbatim}
python3 research/scripts/\
export_confirmatory_family_diagnostics.py \
  --unblinding <frozen-unblinding.json> \
  --out research/artifacts/\
method_v2_confirmatory_family_diagnostics_v1.json
python3 paper/scripts/generate_assets.py
python3 -m unittest paper.tests.test_generate_assets -v
git diff --exit-code -- paper/generated
\end{verbatim}

The paper generator refuses input if any frozen artifact byte hash changes. It
also checks that the family export and confirmatory unblinding commitments
match; the family means reproduce the primary estimate; the terminal reduction
reproduces both method scores and their contrast; and supported-population and
role counts retain their frozen values. The generated manifest records the
SHA-256 of each TeX fragment.
