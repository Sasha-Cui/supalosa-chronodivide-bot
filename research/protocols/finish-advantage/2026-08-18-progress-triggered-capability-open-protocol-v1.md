# Progress-triggered capability reserve: open protocol V1

Status: **prospectively frozen before implementation and before any V1 gameplay outcome**

Recorded: 2026-08-18 UTC.

## Question and fixed architecture

Does late production of a small, universally mobile anti-building capability
convert water-separated and otherwise unreachable draws while retaining the
safe delayed-distance improvement?

Every intervention runs exact external Supalosa and unchanged strict V5 until
the already validated public building-progress trigger fires. It then swaps the
future attack factory exactly as in the prior early or conservative distance arm.
Selected capability arms additionally add two structural missions: one requests
currently buildable side-appropriate prerequisites and the other requests a
bounded air reserve. Allied countries use `JUMPJET`; Soviet countries use `ZEP`.
Produced units are immediately released to the ordinary mission controller; the
capability layer never orders them, owns them persistently, or seizes another
mission's units.

The trigger uses public complete state only. Existing missions and all prior
commands remain unchanged. No map identity, coordinate, country-specific scalar,
outcome, score, endpoint state, or future information enters the policy.

## Complete arms

1. exact external Supalosa;
2. unchanged V5;
3. V5 + early-distance replacement (9,000 / 3,000), no capability reserve;
4. V5 + early-distance replacement + air target 2;
5. V5 + conservative-distance replacement (12,000 / 3,600) + air target 2;
6. V5 + conservative-distance replacement + air target 4.

Production priority is 180 and prerequisite priority 170 in every capability arm.
There are no other counts, priorities, units, thresholds, or target modes.

## Technical gate

All nine countries and both slots on ground and mixed-domain maps must prove:

- exact disabled behavior and deterministic same-seed traces;
- one valid stagnation-triggered swap with unchanged existing mission names;
- side-correct prerequisite order and air-unit name;
- no structure request unless it is currently buildable, unowned, and placeable;
- no unit request after the target count is reached;
- every assigned capability unit is released on the next update;
- capability mission names are unique and never collide with ordinary attacks;
- actual structure or unit requests in Allied, Soviet, slot-0, and slot-1 strata;
- no outcome-bearing telemetry field.

## Fresh open screen

After a pass, use the ten permanently open families, all nine countries,
reciprocal slots, the 24,000-tick literal endpoint, and fresh seed base
`4,227,500,000`. Six arms imply 90 shards and 1,080 games. There are no retries,
filters, substitutions, or subgroup rescue.

Apply the unchanged advancement rule: positive family-clustered paired-score
lower bound versus exact Supalosa; literal-win lower bound above both comparator
point win rates; baseline win-to-loss transitions no greater than draw-to-win
transitions; positive Allied and Soviet effects; and draw upper bound below V5.
Passing authorizes fresh confirmation only.
