## Remote route

The public home page establishes hybrid support for speakers unable to travel.
The online-presentation page requires synchronous Zoom attendance; backup video
does not excuse a no-show. Because the user will not attend physically, the
secretariat must provide the exception procedure and confirmation timing before
any irreversible registration action.

## Generative-AI and double blind

The manuscript contains an identity-neutral Generative AI Disclosure and cites
the official Codex page. Public guidance nevertheless creates a placement
ambiguity: AI text is requested in acknowledgments and affected sections should
cite the system, while double-blind guidance says acknowledgments must be
removed. Ask whether the current separate disclosure section and single system
citation are acceptable or obtain exact anonymous wording/placement.

From initial upload until official selection, do not provide the submitted
paper, confidential reviews, or rebuttal text to a public generative-AI
service. Pre-submission work remains accurately disclosed.

## Named public repository

The anonymous PDF is not publicly posted, but a named public development
repository can make authorship discoverable. The public rules do not resolve
whether code must become private or whether prior visibility affects
eligibility. Obtain a written ruling before changing visibility.

## Reviewer artifact

The current identity-neutral tar.gz is 1,319,395 bytes and contains 60
manifested files. It excludes bot packages, maps, runtimes, raw rows, and
private logs. This readiness does not imply ICAART accepts supplementary
artifacts; ask for the exact PRIMORIS attachment or anonymous-link route. A
clear no-artifact ruling is workable because the paper is self-contained.
